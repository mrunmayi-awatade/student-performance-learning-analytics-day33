# Day 33 - Student Performance & Learning Analytics

## Project Overview
This project focuses on analyzing student academic performance using Python and Data Science techniques.

## Objectives
- Analyze student study hours and attendance.
- Clean and prepare student datasets.
- Perform exploratory data analysis.
- Analyze subject-wise academic performance.
- Identify relationships between numerical variables.
- Build a Linear Regression model to predict student marks.
- Evaluate model performance using statistical metrics.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Import required libraries.
2. Create a student dataset.
3. Explore and clean the data.
4. Handle missing values and duplicates.
5. Perform feature engineering.
6. Calculate descriptive statistics.
7. Analyze attendance and subject-wise performance.
8. Create data visualizations.
9. Perform correlation analysis.
10. Train a Linear Regression model.
11. Evaluate model performance.
12. Export the final dataset and report.

## Files Included
- `student_performance_learning_analytics_day3.ipynb`
- `student_performance_final.csv`
- `student_performance_final_report.txt`

## Dataset
Synthetic student data created for educational and demonstration purposes.

## Outcome
Gained practical experience in data cleaning, exploratory data analysis, visualization, feature engineering, and basic predictive modeling using Python.

## Note
The dataset is synthetic, and the prediction model is intended for educational purposes only.
